    SUBSCRIPTION BUILDER

    Собери свою связь.

    Фильтры выбирают готовые подключения. Новые проверки не запускаются.

    Добавляет (encrypted==true) и (cipher!=aes-256-cfb). Убирает VLESS без TLS/Reality, соединения без шифрования и указанный неподдержанный шифр. Остальные ограничения зависят от версии клиента.
    Как писать фильтры · поля и примеры

    Числа сравниваются через ==, !=, >, >=, <, <=. Дробные числа пиши с точкой. Для текста, true, false и null доступны == и !=.

    lives
    Оставшиеся жизни: от 0 до 3.
    speed
    Скорость передачи в МБ/с.
    latency
    Задержка URL-проверки в миллисекундах.
    stability
    Количество успешных URL-проверок за всё время.
    uptime100
    Процент успехов в последних 100 проверках: от 0 до 100.
    countryCode
    Двухбуквенный код страны выхода: DE, NL, US…
    country
    Название страны выхода, например "Germany".
    protocol
    Протокол: ss, vless, vmess, trojan, hysteria2, socks, http.
    cipher
    Шифр SS или VMess: aes-256-cfb, aes-128-gcm, chacha20-ietf-poly1305, auto… У остальных — none.
    transport
    Транспорт: tcp, ws, grpc, http, httpupgrade, quic (Hysteria2).
    security
    Защита соединения: none, tls или reality.
    encrypted
    true — есть TLS/Reality или шифрование SS/VMess. Например (encrypted==true) оставит SS с шифром и VLESS с TLS/Reality.
    lastCheckSuccess
    Результат последней URL-проверки: true или false.

    Выбор протоколов: (protocol==ss,vless,hy2) — любой из перечисленных; (protocol!=http) — исключить HTTP; (protocol!=http,socks) — исключить оба. Внутри списка действует «ИЛИ», между строками — «И». Например, две отдельные строки (protocol==ss) и (protocol==vless) одновременно не выполняются.

    Также доступны (protocol in [ss,vless]) и (protocol not in [http,socks]). Допустимы псевдонимы: hy2 = hysteria2, shadowsocks = ss, socks5 = socks.

    Пример: 3 жизни, скорость от 1 МБ/с, задержка меньше 300 мс, выход в Германии:

    (lives==3)
(speed>=1)
(latency<300)
(countryCode==DE)

    Текст с пробелами заключай в кавычки: (country=="United States"). (speed!=null) выбирает прокси с актуальным замером скорости. Можно задать до 20 условий; в подписку попадают только живые прокси.

    CONTROL ROOM
    Настройки.
    Изменения сохраняются в базе и применяются к следующим задачам.
    Поиск новых прокси
    Число параллельных проверок меняется в текущем цикле. Увеличение не требует паузы, уменьшение даёт начатым проверкам завершиться.
    Когда приостанавливать поиск
    Все условия объединяются через AND. Пустой фильтр считает все живые прокси. Для условия по speed известная скорость должна быть свежей; null обозначает отсутствие измерения.
    Ручная пауза
    Текущие проверки завершатся, очередь сохранится. Возобновление снимает только ручную паузу.
    Мониторинг известных прокси
    Повторная проверка живых подключений. Пауза Discovery по достигнутой цели не останавливает мониторинг.
    Загрузка подписок
    Ограничения загрузки и размера источников. Параллельность загрузок применяется со следующего сбора.
    Проверка подключения
    TCP-предпроверка выполняется только в Discovery, кроме UDP-протоколов. URL-проверки используются в обоих направлениях.
    Измерение скорости
    Скорость измеряется после успешного URL-запроса. Ошибка измерения скорости сама по себе не отнимает жизнь прокси.
    Контроль инфраструктуры
    При общей неисправности приостанавливаются новые проверки Discovery и Monitoring. Диагностика продолжает работать.
    Сохраняются изменения во всех категориях.
