# golyb_vpn frontend

Public frontend: https://fuck.rkn.golyb-q.moe

API: https://api.fuck.rkn.golyb-q.moe

Only static assets live here. Admin/subscription tokens are entered in the browser.

In Settings → Pages choose GitHub Actions, set the custom domain, then enable Enforce HTTPS.
The CNAME file documents the domain; with Actions, set it in Pages settings as well.

Admin panel: append `?mode=admin` to the frontend URL.
